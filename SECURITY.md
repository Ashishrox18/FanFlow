# Security Policy

## Supported Versions

Only the latest release of FanFlow AI is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| v1.0.x  | :white_check_mark: |
| < v1.0  | :x:                |

## Reporting a Vulnerability

We take security seriously. If you discover a vulnerability, please report it via the following steps:

1. **Do not open a public issue.**
2. Send an email to `security@fanflowai.example.com` with details about the vulnerability, reproduction steps, and potential impact.
3. We will acknowledge receipt of your report within 48 hours and coordinate a fix release within 14 days.
