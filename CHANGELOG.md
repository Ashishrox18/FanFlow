# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

## [1.0.0] - 2026-07-18

### Added

- Core Next.js 14 App Router skeleton in strict TypeScript.
- Dual-model AI Routing framework (Groq Llama 3.3 for conversational FAQ/Emergency, Google Gemini 1.5 for reasoning).
- Persistent global Zustand state for accessibility settings, active venue, and message history.
- Rate-limiting middleware and Zod schema validations for API endpoints.
- Multilingual translation flow, supporting 7 languages.
- Live Crowd Simulation using a deterministic time-seeded model.
- Smart Accessibility Pathfinding avoiding stairs and prioritizing elevators.
- High-contrast emergency assistance feature with immediate action flows.
- Vitest testing framework and Playwright E2E configuration.
- Comprehensive JSDoc annotations and security headers.
